## Overview

Assetto Corsa CSP Config Manager provides a well-organized GUI for navigating and editing the Custom Shaders Patch configuration, grouping CSP's hundreds of toggles and sliders into logical sections with descriptive labels, preset support, and a search function that eliminates the need to scroll through the raw CSP configuration file.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Assetto Corsa CSP Config Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Organized GUI** | Groups CSP settings into logical sections with clear descriptions |
| **Search Function** | Search any CSP setting by keyword across all configuration sections |
| **Preset System** | Save and apply named presets for different quality and performance targets |
| **Inline Help** | Descriptive help text for each setting explaining its visual impact |
